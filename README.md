# 碳感知智算 · 碳台账直接替换版 v0.9

首页新增OBD、legal、VSP条数占比饼图和范围一二三排放占比饼图；排放台账默认按车辆合并为一行，支持展开原始记录。Excel保留原11张表，新增车辆汇总与来源构成，共13张。详见《v0.9使用说明.md》。

Windows 双击根目录 **启动.bat**，进入主系统后点击顶部 **碳台账**，直接打开我们做的排放总览、范围一二三、逐条台账和披露附录。

已删除旧工程台账页面代码、旧 A0–A6 页面组件及其调用入口。不存在新旧页面并列的页签，也不再展示旧碳价、配额和财务风险页面。主系统其他页面继续使用原数据和算法。

页面沿用大前端暗色风格，接收14列CSV后自动归集。OBD实测入账、去重、异常清单、11表Excel导出、表下附注及独立说明册均保留。

操作见 [碳台账使用说明](使用说明_碳台账.md)，模块说明见 [carbon_disclosure](carbon_disclosure/README.md)，验证记录见 [碳账交付验收](碳账交付验收.md)。

更新 GitHub 时保留完整子目录，并删除变更清单中的旧页面文件。源码仓库文件列表本身不会运行网页。
