# 物流企业碳感知智能决策系统

> 给它一笔运单，它告诉你这条线该派什么车、多花多少钱、碳账怎么记；给它一批运单，它告诉你自己的碳数字误差有多大、误差从哪来。

## 一、这是什么

一个面向物流企业的**段级碳计量与决策装置**。

赛场上别人交一份报告，我们交一台机器：评委现场改一行数据，它能自己报警；从任何一个披露数字，能一路查到具体哪一段运单。

它回答五个问题：

| 页面 | 回答的问题 | 关键产出 |
|---|---|---|
| 首页 | 这是什么，参数怎么调 | 全局参数（λ 内部碳价） |
| 1 基准核算 | 现在排多少、数据多脏 | 总碳排 E₀ + 三类数据标记 |
| 2 高排放诊断 | 减排空间在哪 | 四维热点 + 同线碳强度差异 |
| 3 替代方案 | 这条线该派什么车 | 配车方案 + 运营约束校验 |
| 4 成本效益 | 多花多少钱、几年回本 | 成本构成 + 敏感性 |
| 5 碳会计台账 | 怎么记、怎么披露 | 台账六字段 + 附注六要素 |

## 三、架构：业务逻辑只有 4 个文件

| 文件 | 职责 | 输入 → 输出 |
|---|---|---|
| `src/preprocess.py` | 三表清洗、关联、打标记 | `data/raw/` → `wide_data.parquet` |
| `src/optimizer.py` | 排放因子、双轨计量、基准汇总、运营约束 | 宽表 → `baseline_carbon.parquet` |
| `src/evaluator.py` | 四维热点、替代方案、成本效益 | 段级碳排 → `final_report.parquet` |
| `src/pipeline.py` | 顺序调度、出口校验、台账与披露 | 一键复算 + 闸门 |

**三条铁律**

1. **文件越少，找 Bug 越快**：路线不对，只查 1→2→3 三个文件；
2. **一次准备、全程只读宽表**：清洗只在 `preprocess` 做一次；
3. **前端只读不算**：`app/` 里不出现任何业务口径计算，防止答辩现场卡死。

## 四、快速开始

```bash
python -m venv .venv
.venv\Scripts\activate

pip install -r requirements.txt

python -m src.pipeline      # 一键复算，产出三个结果表
streamlit run app/app.py    # 只读结果表，打开五个页面
```

> 当前四个模块为骨架实现，产出的是 3 行示例数据；真实现按 `docs/17` 的 P/O/E/G 模块推进。
