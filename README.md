# 碳感知智算 · 披露碳账主前端接入版 v0.7.1

本版基于 2026-11-13 提供的最新主项目。Windows 双击根目录 **启动.bat**，进入主系统后点击顶部 **碳台账**，默认打开 **披露碳账（范围一二三）**。

已补齐 `carbon_disclosure/`、主系统适配文件和实际调用入口。披露工作台采用原主前端的暗色、蓝色与粉色样式；原工程 E₀、A0–A6 页面分别保留。上传 CSV 自动归集，OBD 实测入账修复继续保留，提供 Excel、短附注和独立说明册。

完整操作与三个页签的区别见 [从主前端进入碳账](从主前端进入碳账_v0.7.md)。模块资料见 [披露模块说明](carbon_disclosure/README.md)，验证结果见 [碳账交付验收](碳账交付验收.md)。

上传 GitHub 时保留解压后的全部目录结构，特别是 `app/`、`carbon_disclosure/` 和 `tools/`。无需额外碳账启动器，也不用单独运行 Node 服务。

## v0.7.1 实际目录修复

补齐当前解压目录漏掉的披露模块及主前端入口。当前页导航保持可点击；主启动器会检查模块文件与入口连接，缺目录或仍是旧入口时明确停止，避免继续显示旧页面。
