## 一、这是什么

一个面向物流企业的**段级碳计量与决策装置**。

赛场上别人交一份报告，我们交一台机器：评委现场改一行数据，它能自己报警；从任何一个披露数字，能一路查到具体哪一段运单。

它回答五个问题：

| 页面 | 回答的问题 | 关键产出 |
|---|---|---|
| 首页 | 这是什么，参数怎么调 | 全局参数（λ 内部碳价） |
| 1 基准核算 | 现在排多少、数据多脏 | 总碳排 E₀ + 四类数据标记（含估算值黄框） |
| 2 高排放诊断 | 减排空间在哪 | 四维热点 + 同线碳强度差异 |
| 3 替代方案 | 这条线该派什么车 | 配车方案 + 运营约束校验 |
| 4 成本效益 | 多花多少钱、几年回本 | 成本构成 + 敏感性 |
| 5 碳会计台账 | 怎么记、怎么披露 | 台账六字段 + 附注六要素 |

> 第 6 页「路线沙盘（预览）」不占五页主线：用高德真路线展示 L1 路线情景，
> 候选路线 + 权重评分后续接入；页面只读结果表，不在前端求解。

## 三、架构：业务逻辑只有 4 个文件

| 文件 | 职责 | 输入 → 输出 |
|---|---|---|
| `src/preprocess.py` | 三表清洗、关联、打标记、缺失填补 | `data/raw/` → `wide_data.parquet` + `data_quality.json` |
| `src/optimizer.py` | 因子表、双轨计量、段级碳排 | 宽表 → `baseline_carbon.parquet` |
| `src/evaluator.py` | 四维热点、同线带宽、方案对比 | 段级碳排 → `hotspots.parquet` / `od_band.parquet` / `final_report.parquet` |
| `src/pipeline.py` | 顺序调度、出口校验、台账与披露 | 一键复算 + `ledger` / `disclosure` / `kpi` / `gate_report` |

**三条铁律**

1. **文件越少，找 Bug 越快**：路线不对，只查 1→2→3 三个文件；
2. **一次准备、全程只读宽表**：清洗只在 `preprocess` 做一次；
3. **前端只读不算**：`app/` 里不出现任何业务口径计算，防止答辩现场卡死。

## 四、快速开始

```bash
python -m venv .venv
.venv\Scripts\activate

pip install -r requirements.txt

python -m tools.launch       # ★ 一键：环境自检 → 一键复算 → 打开五页
                             #   浏览器访问 http://localhost:8501
                             #   Windows 可直接双击「启动.bat」，macOS 双击「启动.command」

# 下面两条是 launch 内部做的事，需要单独调时用：
python -m src.pipeline      # 一键复算：宽表 → 段表 → 热点/方案 → 台账/披露/闸门
streamlit run app/app.py    # 只读结果表，打开五页

# 验收闸门会红 / 能定位失败段
python -m src.pipeline --strict            # 真实数据全绿；演示数据下 5 项 FAIL
python -m src.pipeline --simulate-fail 2   # 期望打印“第 2 段失败”，退出码 1
```

> **`tools/launch.py` 是演示入口**：`src/pipeline.py` 是引擎（算），`tools/launch.py` 是入口（跑）。
> 启动器**任何一步失败都不阻断启动**——缺依赖会先尝试安装，缺高德 key 自动走离线降级，
> 缺结果表会提示先跑 pipeline。答辩现场用陌生电脑也不至于白屏。
> 完整运行手册见 `docs/27_项目运行手册.md`。

> 当前 `data/raw` 已放附件1/附件2，运行即实测模式；把附件移走则自动回退 6,000 行演示样本。
> 真实数据的 Sheet 结构、去重键、75 车型映射见 `docs/21_真实数据表结构与接入记录.md`。
>
> **当前真实数据**：`python -m src.pipeline` 退出码 **0**，闸门 PASS 22 / FAIL 0。
> E₀ 4,502,042.41 kg 精确；均速 49.51 对官方速度文件 49.57 在 ±0.1 内，已在说明列标注。
>
> **高德地图（T7，可选）**：配好 `config/amap_*` 三把 key 后，
> `python -m tools.route_fetch` 预取 310 条真路线（已入库，团队共享），
> 第 3 页出现「动态路线」区块（高德真底图 + 路径级碳-成本联合决策）。
