## 实车数据没有 DID 手册怎么办（J6L220 国六柴油）

2026-11-11 收到 J6L220（16 t 国六柴油）的 29 个 CAN 抓包 CSV（39,645 帧 / 18,619 条 0x62 应答 / 83 个 DID），
靠"页面轮询结构 + 量纲守恒 + 单调性 + 相关性 + 停车行驶对照"反推出 **0x0166（每循环喷油量）× 0x0165（转速）** 这条油耗主通道，
整批窗口积分 **13.61 L → 35.8 kg CO₂**（喂进官方守恒法校验得 13.53 L → 35.58 kg，偏差 0.6%）；映射表见 `config/did_map_j6l220.json`，解码器 `src/obd_did_j6l220.py`，
方法论与缺口清单（车速/里程/大气压确实不在本批数据里，需补采）见 **`docs/72_J6L220_国六柴油_DID反推与实测碳排接入.md`**。

```bash
python src/obd_did_j6l220.py --selftest                 # J6L220 DID 映射表 + 解码器自检
python tools/j6l220_calibrate.py --input <抓包目录>      # 逐段“喷油积分 vs Δ0x0199”定标体检
python tools/j6l220_contract_check.py --input <抓包目录> # 解码行 → 契约校验 → 官方守恒法算碳（端到端）
```
