# 碳账：主系统内的披露模块 v0.9

首页新增OBD、legal、VSP条数占比饼图和范围一二三排放占比饼图；排放台账默认按车辆合并为一行，支持展开原始记录。Excel保留原11张表，新增车辆汇总与来源构成，共13张。详见《v0.9使用说明.md》。

本版统一使用根目录的 `启动.bat`（Windows）或 `启动.command`（macOS/Linux）启动整个主系统，随后点击主导航“碳台账”直接进入。操作见 [碳账快速开始](../碳账快速开始.md)。已移除额外的“启动碳账”脚本，正常使用不需要单独启动本模块服务器。

本项目接收已计算的排放事实，完成规则检查、去重、范围/月度归集、台账查询、异常查询与Excel试算导出。原始排放量由上游提供，本项目不按活动量乘因子重算碳。

本版按用户提供的ESG报告参考页调整为“与主系统一致的暗色主表＋表下短附注＋独立说明册（红白印刷版）”。范围一采用港交所与发改委文件参考；范围二采用港交所与2023年电力因子公告参考；范围三采用港交所与《企业价值链（范围三）核算与报告标准》（2011）参考。所选文件与项目参数的差异、港交所文件的版本状态均在说明册中登记。

在主表右上方或表下注释后点击“阅读完整说明册”可在页面中阅读，点击“下载说明册 PDF”可下载7页独立文件。单文件HTML已内嵌PDF，无需联网下载说明册。表下注释也随Excel输出到“07_披露附注_草稿”。只有两个月模拟输入，因此主表按实际月份展示。

2026-11-11已根据用户提供的仓库源码快照补全当前模拟样例的333条生成输入、实际公式、代码位置和舍入说明，原始凭证保持待补。首次载入样例使用已补资料；浏览器已有批次和手动清空的内容不会被自动覆盖，可使用配套附录JSON备份恢复。新上传批次不自动套用模拟解释。

## 主系统内使用

使用主启动器运行整个系统，直接进入当前披露系统。默认载入用户提供的模拟数据，页面会清楚标注“模拟”和“未经人工业务审核”。

`dist/index.html`、根目录离线HTML和模块静态服务器保留为开发测试及离线备份资源；日常使用以主系统入口为准。

1. 查看模拟数据效果，或选择/拖入UTF-8 CSV。
2. 上传新文件后确认“数据性质”和“排放口径”；CSV自身未包含这些完整说明，不自动把真实上传标为模拟或CO₂e。
3. 按月份、范围、车牌/车辆/趟次/事实编号筛选。
4. 查看有效主账、旁证与全批处理清单；点详情查看接收的14字段。
5. 在“披露附录”中补充本期附注、方法与因子、逐条计算和证据说明；标准目录提供官方参考入口，没有的资料保持待补。
6. 点击“导出Excel”，下载十三张表：原有六张主线表及五张附录表，并新增车辆汇总和来源条数构成。
7. 使用“备份附录”保存本批原始CSV和附录资料；换浏览器或设备时先载入相同CSV，再“恢复附录”。

主账、旁证和月度导出使用页面当前筛选；处理清单始终保留全批，并在页面与工作簿中说明。

## 已实现规则

- 必须包含现有14字段，允许调整列顺序；其他额外列保留在原始批次中。
- 同一趟次、月份、范围与活动有legal时优先采用；没有legal时采用OBD实测结果。VSP仅作旁证；同源多条候选暂不汇总，没有趟次的记录按fact_id独立接收。
- 上游`scope`、`period`按原值接入，不擅自改范围或改用开票日期。
- 同一`fact_id`且核心内容相同只计一次；计算时间和备注变化不视为新排放。同ID核心内容冲突则整组暂不计入。
- 负排放、缺因子或版本、非法范围/期间/轨道、缺活动、缺排放量、列数异常等保留原因并单列；未知不补0。
- 非行程电力记录不要求车牌或趟次。
- 十进制精确加总；页面舍入显示，Excel保留输入数值精度。Excel本身的数值精度限制仍适用。
- 最近5批数据保存在当前浏览器；重复载入同一内容复用批次，不累加为新排放。当前报表只统计所选批次，不跨历史批次叠加。

## 主线边界

范围分类的独立解释见[范围一二三划分依据](范围一二三划分依据.md)，包括分类条件、官方参考章节、当前模拟数据映射和待确认资料。该说明不替代标准正式采用或组织边界批准，不改变当前CSV的scope值。

本版不含人工业务审核、三方油量核验、财务区间油耗、空转判断、用户登录或云端多用户存储。已提供附录登记和关联能力，原始计算与证据仍需上游提供；字段检查通过或附录已登记不代表业务或证据已经核验。

附录资料与原始排放事实分开保存。修改参考因子、公式说明或证据登记不会重新计算或覆盖主账排放。测试指定2.63、0.53、0.5568仅在已知模拟版本中预填，并与尚待提供的正式出处分开。真实或未注明批次不自动套用这些模拟因子。

当前参考目录已按用户本次选择更新，先前的国标及通用范围一二文件不再列作主要参考。文件选定不代表已经核验真实组织边界、正式参数或完整上市合规。2021年电力因子仅作现有模拟参数的历史数值对照。

当前仅导出CSV能够支持的独立试算工作簿。没有输入来源的财务成本、配额、年化和完整披露指标未自动生成；未冒充已完成原有全部回填模板。

本版提供可提交GitHub的完整源码和自动检查流程，没有发布到外部平台。

## 后续接入

- `dist/core.js`：独立数据处理和报表数据结构，可在浏览器或Node.js复用。
- `dist/xlsx.js`：将同一报表数据结构写入标准XLSX，不将任何输入文本执行为公式。
- `dist/appendix.js`：独立附录资料结构、待补识别、备份恢复与附录报表数据。
- `dist/appendix-ui.js`：附注、因子与逐条证据的登记界面。
- `dist/app.js`：页面和本机批次保存。
- `dist/index.html`、`dist/styles.css`：可替换的页面呈现。

接入现有系统时，保留核心处理规则，替换输入、存储和页面集成；按目标系统确定权限及运行方式。

## 验证

在本目录使用Node.js运行 `node --test`，无需安装依赖。另有Python服务器与主系统接入检查，具体命令见 [接入说明](../docs/碳账接入与交付说明.md)。

测试覆盖真实提供的模拟样本、重投、核心内容冲突、跨范围事实、主账旁证隔离、零与缺失、非行程电力、十进制精度、CSV引号/换行、筛选与导出一致性、公式文本安全等。

模拟样本基线：342行输入，328条有效主账、5条旁证、3条重投、6条被拒。试算合计98,569.602 kgCO₂e；该值是按本版已声明规则对模拟输入的加总，不是实际企业披露结论。
