# 附录怎么填

打开附录版页面，在左侧点击“披露附录”。先用模拟数据练习；没有拿到的真实资料保持待补。

v0.3主表已增加表下短注；“阅读完整说明册”与“下载说明册 PDF”提供详细分册。所选参考组合已按用户指定统一为港交所、发改委、2023年电力公告和范围三标准；逐条资料继续记录实际计算来源，不因为更换参考文件而改写上游数值。

## 第一次先做这两件事

1. 在“01 本期附注”填写报告主体：公司、车队或项目名称。组织边界用于说明本期纳入哪些车辆、场地和业务；不确定时留空。点“保存附注”。
2. 查看“03 方法与因子”：已知模拟版本会列出测试指定因子。只有拿到实际出处后，才在“补充 / 修改”中登记文献、页码和链接。不要把“项目指定”改写成某标准统一规定。

## 四个入口分别做什么

| 入口 | 填写或查看的内容 |
|---|---|
| 01 本期附注 | 主体、边界、正式采用标准、来源、各范围覆盖和缺失事项 |
| 02 标准依据 | 查看范围分类与披露的官方参考入口；具体采用版本由项目明确 |
| 03 方法与因子 | 记录名称、数值与单位、边界、参考方法、项目来源和正式出处 |
| 04 逐条追溯 | 按事实编号登记上游实际输入、实际公式/模型、输入来源、分摊与舍入、原始证据说明和可选链接 |

## 有了逐条计算材料以后

进入“04 逐条追溯”，找到对应记录，点击“补充说明”。照上游原始资料填写，不从排放量反推耗油量。证据没有链接也可以先写文件名称或证据编号。保存后显示“已登记，未经核验”；登记资料不会重新计算原始排放。

也可以在“排放台账”打开一条记录的“详情”，直接查看和补充该记录的附录。

## 导出与留存

- 顶部“导出Excel”同时输出主线报表和五张附录工作表。
- 主账、月度和逐条追溯按当前筛选导出；处理清单保留全批，方法目录匹配当前筛选。标准目录为通用参考，本期附注仍说明整个批次的边界。
- “备份附录”另存当前CSV与附录资料。恢复时，先载入相同CSV，再点“恢复附录”选择备份文件。
- 编辑资料默认只留在当前浏览器，重要内容保存后还应导出Excel或备份附录。

材料待补不等于排放为0；有证据编号也不等于已经取得或核验原件。未补齐的资料会列在Excel的“附录待补资料”中，方便向上游逐项索取。
