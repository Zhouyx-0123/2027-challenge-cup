## 2. 权限级别定义

| 级别 | 含义 | 能做什么 |
|---|---|---|
| **O** — Owner | 唯一责任人 | 可直接改动；对正确性负责；决定实现方式 |
| **R** — Reviewer | 第二双眼睛 | 不主导实现；该文件的 PR 必须经其通过；可以"口径不符"打回 |
| **C** — Contributor | 协作人 | 可提 PR，改动需 Owner 同意 |
| **N** — Reader | 只读 | 可读、可提 Issue，不得直接改 |

**三条铁律**
1. **单写者**：任何文件同一时间只有 1 个 Owner；
2. **跨域必审**：改别人 Owner 的文件，PR 必须由该文件 Owner 或 Reviewer 批准；
3. **口径集中**：任何口径数字（排放率、补贴、年化系数、成本口径）全项目只允许一处定义——代码常量或 `docs/08`；改数字必须 PR 写明"改前值 / 改后值 / 依据"，并同步 `docs/08`。
