## 一、业务逻辑全景

### 1.1 一句话与输入输出

给三张原始表（订单 / 运单 / 车辆），系统输出五件事：**段级碳排放 → 四维热点 → 替代方案（电动/氢能/组合）→ 成本效益与敏感性 → 碳会计台账与披露附注**，全部在一个**离线可运行的本地网页**上呈现。

### 1.2 业务链（从左到右五步）

| 步 | 业务含义 | 承载文件 | 主笔 | 输出物 |
|---|---|---|---|---|
| ① 数据准备 | 三表关联、清洗、合成唯一宽表 | `src/preprocess.py` | 蒿韵丞 | `data/processed/wide_data.parquet` |
| ② 碳核算 | 查因子表 + 内插 → 每段碳排放；基准汇总；运营约束校验 | `src/optimizer.py` | 杨盛文 | `baseline_carbon.parquet` |
| ③ 分析与财务 | 高排放热点（四维）、替代方案、成本效益与敏感性 | `src/evaluator.py` | 曾广 | `final_report.parquet` |
| ④ 调度与台账 | 一键串起三段；出口对拍闸门；台账六字段 + 披露附注打包 | `src/pipeline.py` | 周嬴鑫 | 结果表 + 闸门报告 |
| ⑤ 呈现 | 首页 + 五页，只读结果表，不做业务计算 | `app/` | 周（框架+1–2 页）/ 杨（3–5 页） | 可交互界面 |

### 1.3 数据口径（对拍红线，全部程序化验证）

- **独立路段 33,214**（运单表 36,329 行去重）/ **总里程 4,690,435.81 km** / **有效速度样本 33,213** / **门到门均速 49.57 km/h ±0.01**
- 30 t 载重排放率 **14.67 g/s ±0.01**；VSP3 平行校验 **16.53 g/s（偏差 12.68%）**
- 三个必踩的坑：订单号 `-1-1-` 后缀 / 附件2 隐藏 sheet（16,413 行桥接表）/ 载重靠车型表（75 车型，`mass_basis` 逐车型核对）
- 速度 >100 km/h 共 1,298 条（3.9%）：**标记不删除**（删除会改动总里程口径）
- 核算链：因子表（文献[1] 表8）→ 查表 + 线性内插得 ER(g/s) → `F(g/km) = ER × 3600 / v`（v = 50 km/h）→ `kg = F × 里程 / 1000`

### 1.4 分析与财务口径

- 四维热点：车型 / 里程段 / 线路 / 月份
- 替代方案校准标的：电动 **117 辆**
- 成本效益校准标的：**4,809 万 / 77.4% / 9.6 年**（成本构成逐项对账：购置净 + 能耗 + 维护 + 补贴 = 总成本）
- 双口径开关：赛题口径（默认）｜碳价延展口径（100 元/t，前端一个开关）

### 1.5 碳会计口径（第二卖点）

- **台账六字段**：核算日期 / 核算边界 / 碳排放量 / 配额缺口（赛题口径填"—"）/ 账面履约成本 / 披露附注
- **附注六要素**：核算边界 / 排放因子来源 / 关键假设 / 数据期 / 年化系数 3.0417 / 局限性
- 规则：台账挂在**方案级结论**（3 行量级），不给 36,329 条运单逐段记账；台账数字与第 1 页同源

### 1.6 工程师定稿的架构原则（为什么是四个文件）

1. **文件越少，找 Bug 越快**——全部业务逻辑只有 4 个文件，不新增（新增须 PM 批准）
2. **一次准备、全程只读宽表**——清洗只在 preprocess 做一次
3. **前端只读不算数**——app 不出现业务口径计算（乘系数、折算、成本公式）
4. **原始数据永不入库**——网盘共享，.gitignore 兜底
5. **路线不对，只查三处**——`preprocess → optimizer → evaluator`

## 四、并行还是串行？（时间差说明）

### 4.1 结论：**四线并行为主，三个节点强制先后**

- **并行四线**：蒿（数据）｜杨（引擎 + 3–5 页）｜曾（分析财务）｜周（pipeline + 框架 + 1–2 页）——W1 第一天就可以同时开工。
- **强制先后（三个节点）**：
  ① **契约冻结**（W1 周六）→ ② **真宽表落盘**（W2 中）→ ③ **真结果表 + 闸门全绿**（W2 末）→ ④ **五页联调**（W3 末）
- **并行秘诀**：所有人按"契约 + mock 数据"先开工不等真数据——杨用 mock 宽表开发引擎、曾用 mock 碳排搭分析框架、周/杨用仓库里已入库的 3 行演示表搭页面。真数据一到，只换数据源，不返工逻辑。
