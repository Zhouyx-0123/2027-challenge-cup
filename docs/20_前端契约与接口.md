# 前端契约与接口（第 1 版）

**用途**：在写任何页面之前，先把"页面能看到什么"定死。这份文件是 W1 定字段会（C1）的输入。
**原则**：页面**只认接口，不认文件**。改列名只改 `services.py`，五个页面一个字都不动。

---

## 1. 三层结构，谁碰谁

```
data/processed/*.parquet      ← pipeline 产出，前端只读
        ↓
app/services.py               ← 唯一取数入口（缓存、兜底、列名映射）
        ↓
app/components/*.py           ← 版式、图、标记（不含业务）
        ↓
app/pages/*.py                ← 只排列，不计算
```

**三条硬规矩**

1. 页面里出现 `pd.read_parquet` 就是错——必须走 `services`；
2. 页面里出现任何"乘系数、除以、减补贴"就是错——那是 evaluator 的活；
3. 文件缺失、依赖缺失、列缺失，**一律显示空状态，不抛异常**——答辩现场不能红屏。

## 3. 服务层接口（`app/services.py`）

```python
available() -> dict[str, bool]        # 哪些结果表已经有了
wide(), segments(), scenarios()       # 三张主表，缺了返回空表
hotspots(dim=None), od_band(), ledger()
disclosure() -> dict
kpis() -> dict                        # 七个数字，缺了按键给 None
column_ok(df, cols) -> list[str]      # 检查列是否齐
```

**约定**

- 所有函数都带缓存，页面里可反复调用；
- 缺表返回 `pd.DataFrame()`，不抛异常；
- 缺列由 `column_ok()` 报告，页面据此显示"该表还没就绪"。

## 4. 组件接口（`app/components/`）

| 函数 | 作用 |
|---|---|
| `setup(title)` | 页面配置（每个页面第一行） |
| `page_header(title, question, badge)` | 页头：标题 + 一句话问题 + 状态标签 |
| `kpi_row(items)` | 一行指标卡，items = [{label, value, help}] |
| `conclusion(text)` | 页脚"本页结论"色带（答辩照着念） |
| `empty_state(need)` | 空状态：告诉你缺哪张表、跑什么命令 |
| `section(title, desc)` | 小节标题 |
| `flagged_table(df, ...)` | 带三色标记的表格 + 图例 |
| `flag_summary(df)` | 三类标记的计数（首页与第 1 页用） |
| `bar / line / scatter` | 图表封装（统一 Streamlit 原生） |

## 5. 页面模板（五页都长这样）

```
① 页头      这个问题是什么（一句话）
② 指标卡    3–4 个数字，回答"多不多"
③ 主图      一张图，回答"在哪"
④ 明细表    可筛选，回答"具体是谁"，带标记
⑤ 结论带    一句话，答辩照着念
```

**每页必须有 ⑤**。评审只记得住每页那一句话。

---

## 6. 全局参数：λ 只出现一次

内部碳价 λ（元/吨 CO₂e）和双口径开关，**只在侧边栏出现一次**，通过 `st.session_state` 共享。

- 第 3、4、5 页读同一个 λ；
- 各页自己再放一个滑块 → 两个页面的数字一定打架；
- 默认值写死在 `optimizer.py` 常量里，前端只读不改。

---

## 7. 三种标记的颜色与文案（全项目统一）

| 标记 | 颜色 | 文案 | 处理 |
|---|---|---|---|
| flag_dup | 灰底 | 重复行（已去重） | 默认不进统计 |
| flag_anomaly | 黄框 | 时间戳异常，保留计碳 | 保留 |
| flag_basis | 黄框 | 载重按总质量换算 | 保留，显示原值 |

固定在表格下方放一行图例，别让评委猜。
