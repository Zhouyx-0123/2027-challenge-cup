## 1. 审计方法（可复现）

本机无 pyarrow / streamlit（离线），所以做了两层替身，**不改仓库代码**：

1. **流水线**：把 `pd.read_parquet` / `DataFrame.to_parquet` 换成 pickle 垫片，
   然后真跑 `python -m src.pipeline`；
2. **页面**：给 `streamlit` / `plotly` / `jinja2` 装最小替身，`runpy` 逐个执行

3. **单元测试**：对路线连接这类纯函数用合成 DataFrame 直接断言。

复现（在临时目录建垫片，**不要**放进仓库，否则会把 parquet 写成 pickle）：

```python
# _audit/parquet_shim.py
import pickle
import pandas as pd

def _to_parquet(self, path, *a, **k):
    with open(path, "wb") as f:
        pickle.dump(self, f, protocol=5)

def _read_parquet(path, *a, **k):
    with open(path, "rb") as f:
        return pickle.load(f)

pd.DataFrame.to_parquet = _to_parquet
pd.read_parquet = _read_parquet
```

```bash
# 把上面的垫片存成 parquet_shim.py（与本命令同目录），再执行：
python -c "import parquet_shim; parquet_shim.install(); from src import pipeline; pipeline.main([])"
```

> 注意：垫片会把同名 `.parquet` 写成 pickle。**跑完务必 `git checkout -- data/processed` 还原**，
> 否则下一次真跑 pyarrow 会读到损坏文件。

结果：`PASS 22｜FAIL 0｜SKIP 0`，耗时 7.2 s，E₀ 精确命中。

## 4. 未改项的具体改法（给下一轮）

**D4/D5 · 把页面计算搬走**
正解不是"页面调 src"（会破坏 A0：services 不碰算法），而是**让 evaluator 预计算、页面只读**：

1. `evaluator.build_lambda_curve(schemes, lam_max=1000, step=10)` →
   写 `data/processed/lambda_curve.parquet`（列：`scenario, lambda, annual_save_wan, payback_years`）；
2. `services.lambda_curve()` 读它；`4_成本效益.py` 只做 `charts.line_multi(curve, ...)`；
3. 回本年限、含 λ 节省、推荐翻转点全部由 evaluator 出，页面删掉 `annual_save_wan/payback_at` 两个函数；
4. 页面 1 的 KPI 直接用 `kpi.json`（`services.kpis()` 已备好），不再自己 `sum`。

**D6 · 闸门自洽项**
在 `_structural_items` 的 `schemes` 项里追加断言（不新增计数）：
`max|emission_t − e0_t×(1−reduction_pct/100)| ≤ 0.01 t`，不满足即 FAIL。

**D7 · 路线连接向量化（已完成）**
不是把 `map` 换成 Series 索引（那样会丢 NaN 语义），而是**先把路线表摊平成 4 张
`{键: 值}` 字典，再整列 `Series.map(dict)`**（C 层查找）：

```python
km_map  = {k: rec.get("distance_km") for k, rec in index.items()}
...
route_km_s = pd.to_numeric(keys.map(km_map), errors="coerce")
```

坑：逐行版对**未命中**的行 `continue`，因此不会走"时长缺失 → 按 50 km/h 反推"的兜底；
向量化时必须写成 `need_fill = hit & (route_min <= 0) & (route_km > 0)`，否则未命中的行
会被凭空补出时长，`kg_co2_route_phys` 立刻漂。A/B 对照（800 行，含缺键/NaN/0 距离/
NaN 时长/重复键）已验证两版**逐位一致**；33,214 段实测 4,831 ms → 53.9 ms。
