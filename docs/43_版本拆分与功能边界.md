# 版本拆分与功能边界（V1.0 软著冻结）

> 结论：当前算软件，算“单机/内网部署的物流碳核算与决策分析软件”，不是带账号体系的 SaaS。  
> 软著不要求登录、不要求上线；V1.0 不添加登录界面。

## 1. 现在到底是什么

| 维度 | 当前状态 |
|---|---|
| 形态 | Python + Streamlit Web 应用，可本地/内网运行 |
| 用户 | 无账号、无登录、无权限隔离；单实例使用 |
| 数据 | 通过 data/raw 文件夹 + pipeline 输入，页面只读 data/processed |
| 功能 | 8 个模块：概览/核算/诊断/方案/成本/台账/路线/测算/TCO |
| 输出 | 页面展示、结果表、台账/披露、闸门报告 |
| 上线 | 未部署；软著不要求部署 |
| 登录 | **没有，也不在 V1.0 范围** |

## 2. 拆成四个部分

### Part A：软著冻结版 V1.0（现在登记）

范围：

- 现有 8 个页面；
- 碳核算引擎（法定物理轨 + VSP 技术轨）；
- 数据预处理与结果表；
- 台账/披露/闸门；
- 无登录、无上传页、无多用户。

用途：

- 软著申请；
- 比赛演示；
- 当前可运行版本。

**不要在这个版本里加登录、权限、上传页。**

### Part B：数据输入增强 V1.0.1（最高产品优先级）

范围：

- Excel/CSV 输入模板；
- 校验 CLI；
- 错误报告；
- 不覆盖旧结果；
- 仍然不改前端。

这是“用户怎么把数据放进来”的交付，不是 SaaS。

### Part C：产品化 V1.1（暂缓）

只有确定要对外运营时才做：

- 登录/用户表/密码哈希/会话；
- 多用户与权限；
- 上传页/任务队列；
- 审计日志；
- 隐私政策与数据授权。

这会改变软著版本、手册截图和部署方式，必须单独排期。

### Part D：比赛/答辩版

- 本地或内网运行；
- 合成/脱敏演示数据；
- 5 分钟演示脚本；
- 截图/视频兜底；
- 不需要登录。

## 4. 登录界面的结论

### 软著

**不需要登录。**

软著审查看源程序、文档、功能，不看是否有账号体系。  
本地工具、单机软件、无登录 Web 应用都可以登记。

### 比赛

**不需要为了比赛加登录。**

- 现场本机演示；
- 或内网访问；
- 如需限制访问，用反向代理 Basic Auth（Caddy/Nginx），不改 app；
- 不要把“登录”写进 V1.0 手册。

### 产品化

如果以后要对外运营，登录才需要，属于 V1.1：

- 用户表；
- 密码哈希；
- 会话/过期；
- 角色权限；
- 审计；
- 隐私政策；
- 数据授权。

单独排期，不要插在软著提交前。

## 5. 软著材料怎么写

软件名称：

~~~text
碳慧智算物流碳感知智能决策系统 V1.0
~~~

软件形态写：

~~~text
单机/内网部署的物流碳核算与决策分析软件；
无账号体系；数据由本地文件导入；页面只读结果表。
~~~

不要写：

- SaaS；
- 多用户平台；
- 在线注册/登录；
- 云端上传。
