## 1. 先说三件最要紧的事

### ① 颗粒物不是碳排放

PM 是**污染物浓度**（mg/m³），CO₂ 是**排放质量**（kg/km）。两者不是一回事，量纲不同、口径不同、监管口径也不同。

所以：**PM 数据不进 E₀ 主账、不进闸门目标值、不进台账的碳排数字。**

但它有用 —— 它的角色和「发票油量」**完全同构**：

| | 谁给的 | 性质 | 作用 |
|---|---|---|---|
| 因子表 | `src/optimizer.py` | **估算** | 算出一个碳排数 |
| 发票油量 | 发票识别 | **实测** | 消耗了多少油 → 反推百公里油耗 → 与理论值比对 → 异常审计 |
| **颗粒物实测** | 单片机 | **实测** | 实际排了多少颗粒 → 反推排放率 → 与理论值比对 → **异常审计** |

**发票给"消耗了多少"，PM 给"实际排了多少"，因子表给"估算应该是多少"。三者交叉才能审计因子表。**

### ② 设备必须能算出 g/km，否则这批数据挂不上碳账

瞬时浓度是**速率量**，没有时间跨度和里程跨度就不是排放量。所以契约把 `flow_m3h`（采样流量）列为**必填**，并要求给出 `dist_km`（里程）或 `speed_kmh`（车速）：

```
排放质量(g)  = 质量浓度(mg/m³) × 流量(m³/h) × 采样时长(h)
排放率(g/km) = 排放质量(g) ÷ 窗内里程(km)
```

**这是整个接口最重要的一条约束。** 只有浓度没有流量的设备，采回来的数据对碳账没有价值 —— 这是"必须留好接口"最实质的含义。

### ③ 没有可核查来源的换算系数，一律不写

本契约与 `src/telemetry.py` 里**不含任何 PM→碳排 / PM→油耗 的系数**。照 `config/invoice_spend_factors.json` 的规矩（"默认不放任何金额因子，禁止使用无来源的行业均值或万能系数"）。

理论值与实测值的比对，等真实数据标定出来再做。**宁可空着等实测标定，也不塞一个查不到出处的系数。**

## 2. 字段契约（摘要，完整见 `config/telemetry_contract.json`）

### 必填（缺任意一条 → 该读数判 `needs_review`，不是丢弃也不是填 0）

| 字段 | 单位 | 说明 |
|---|---|---|
| `device_id` | — | 设备唯一 ID，建议 `PDM-GZ-001`（类型-区域-序号） |
| `ts` | ISO8601 **带时区偏移** | 裸时间戳判无效；设备须 NTP 对时，失败置 `clock_drift` |
| `pm25_mg_m3` | mg/m³ | **注意不是 μg/m³** |
| `flow_m3h` | m³/h | 采样流量 —— 算 g/km 的必要条件 |

### 强烈建议

| 字段 | 单位 | 作用 |
|---|---|---|
| `dist_km` | km | 累计里程；与 `speed_kmh` 二选一必给 |
| `speed_kmh` | km/h | 车速，VSP 工况判别的关键量 |
| `od_key` | — | 起终点，格式与 `route_od.parquet` 的 `od_key` **完全一致**（`起点网点|终点网点`） |
| `plate` | — | 车牌（**可选**，路侧站没有）；属可识别信息，须脱敏 |

### 可选

`pm10_mg_m3`、`co2_ppm`（⚠️ 是**浓度**不是排放量）、`so2_mg_m3`、`nox_mg_m3`、`temp_c`、`press_hpa`、`load_kg`、`engine_rpm`、`fuel_type`、`qc_flags`

### 质控标记（`qc_flags`，数组）

`preheat`（预热中）、`sensor_fault`、`calib_stale`（标定过期）、`low_flow`、`overflow`、`power_reset`、`clock_drift`、`duplicate`、`manual`

标记为 `preheat / sensor_fault / calib_stale / low_flow / overflow / power_reset / clock_drift` 的读数**不参与排放率标定**（`src/telemetry.py` 的 `QC_EXCLUDE_FROM_RATE`）。

## 3. 设备端怎么交付

### 方式 A · 文件投递（首选）

设备把当批读数写成 CSV，落到共享目录（网盘 / 局域网共享 / SD 卡回传）：

```
data/raw/实时/pm_YYYYMMDD[_批次].csv
```

- 编码 UTF-8（带 BOM 亦可）
- 必须含表头行，列名用上面的字段名
- 多批追加时表头只写一次

**为什么首选**：很多单片机开发板的网络不稳定，文件投递最可靠；断网时数据不会丢，联网后补传即可。

### 方式 B · HTTP 直传（网络稳定时）

```http
POST /ingest/pm
Content-Type: application/json; charset=utf-8
X-Device-Token: <设备令牌>

{"readings": [ { ...读数... }, { ...读数... } ]}
```

也接受单条读数对象。响应：

```json
{"ok": true, "counts": {"input": 2, "ok": 2, "rejected": 0, "devices": 1, "written": 2}}
```

令牌从 `config/ingest_token.txt` 读（**不进版本库**）。未配置令牌时接口不校验 —— 仅限本机演示，**不要暴露到公网**。

### 方式 C · MQTT（预留）

topic：`pm/{device_id}/telemetry`，payload 与 HTTP body 同构，QoS 1、retain false。
设备端选型确定后再启用（`tools/ingest_pm.py` 留了 `--mqtt` 位置）。

## 4. 后端这边已经就位的部分

| 位置 | 作用 | 纪律 |
|---|---|---|
| `config/telemetry_contract.json` | 机读契约，**设备端与后端共用这一份** | 不含任何换算系数 |
| `src/telemetry.py` | 校验 / 归一 / 去重 / 采样窗 g/km / 质控统计 / 落盘 | 纯函数、可单测；不读宽表、不写 `data/processed`、不进闸门、不 import `preprocess` |
| `tools/ingest_pm.py` | 接收端：文件轮询 / HTTP / 预留 MQTT | 只做「校验 → 落盘 → 记账」，**不做业务计算**（同 `tools/route_fetch.py` 的 I/O 原则） |
| `tests/test_telemetry.py` | 33 项契约测试 | 必填/时间戳/量程/质控/去重/幂等/纪律 |

### 跑起来

```bash
# 文件模式（收一批）
python -m tools.ingest_pm --input data/raw/实时/pm_20261025.csv --dry-run

# 轮询监听
python -m tools.ingest_pm --watch --dir data/raw/实时 --interval 30

# HTTP 接收端
python -m tools.ingest_pm --serve --port 8760 --token-file config/ingest_token.txt
```

退出码：`0` 成功 ｜ `1` 系统错误 ｜ `2` 输入错误（照 `docs/42 §7`）。

## 5. 实测行为（端到端）

喂 8 条读数（1 条重复、1 条缺流量、1 条 `preheat`）：

```
读入 8 条｜可用 6｜拒绝 2｜设备 2
[REJECT] 第 3 条 → 与第 2 条重复（设备 PDM-GZ-001 @ 2026-10-25T10:00:00+08:00）
[REJECT] 第 4 条 → 缺必填数值字段 flow_m3h
采样窗：可用 3 / 共 4        ← preheat 那个窗被排除
质控标记：{'preheat': 1}
```

HTTP 模式：`POST → 200`、无令牌 `→ 401`、`GET /health → 200`。

## 7. 给设备同学的 6 条要点

1. **流量（`flow_m3h`）是必填**，没有它采回来的数据算不出排放率，等于白采。
2. **时间戳必须带时区**（`2026-10-25T14:03:22+08:00`），并且要对 NTP；没对上就置 `clock_drift`。
3. **单位是 mg/m³**，不是 μg/m³ —— 差 1000 倍，别搞错。
4. **里程给累计值**（`dist_km` 递增），后端按差值算每窗里程；没有里程就给车速。
5. **缺的数据写 `null`，不要写 0**。0 是合法的浓度值，混同会造出假的零排放。
6. **异常要标 `qc_flags`**（预热、标定过期、流量偏低…），标了的后端会自动排除，不让它污染标定。
