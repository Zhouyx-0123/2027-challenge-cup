| 令牌 | 值 | 用途 |
|---|---|---|
| `--color-ink` | `#07080a` | 页面底 |

| `--color-tide` | `#46b7ff` | 潮汐蓝高光 |

两段关键机制，原样搬进本项目：

```css
/* 潮汐光晕 */
.tide-glow{background:radial-gradient(60% 55% at 50% 8%,#46b7ff2e 0%,#2e7dff0f 40%,#0000 72%)}

/* 颗粒 */
.grain:before{content:"";opacity:.035;mix-blend-mode:overlay;
  background-image:url("data:image/svg+xml,...feTurbulence...")}
```

弹簧缓动曲线：`cubic-bezier(.22,1,.36,1)`（原站入场动画与卡片 hover 统一用它）。
卡片 hover：`hover:-translate-y-1` + `shadow-[0_18px_60px_-18px_rgba(70,183,255,0.4)]`（蓝色投影）。

### 1.2 coolors 的「无边界」手法（沿用 docs/46）

卡片没有 `border`，边界由 `box-shadow: hsla(250,3%,0%,.075) 0 0 0 1px` 画出——
**零偏移零模糊的实心描边，但写在 box-shadow 里，不占布局尺寸**，所以换圆角/换背景都不抖。

### 1.3 本项目的取法

| 来源 | 负责什么 |

| scrolltide | 底色体系、潮汐背景、颗粒、弹簧曲线、药丸导航 |

## 3. 顶栏：悬浮玻璃药丸条（`app/components/main_nav.py`）

结构：`st.container(key="cm_nav_bar")`（吸顶、无材质）→ `st.container(key="cm_nav_pill")`（玻璃药丸）。

```css
.st-key-cm_nav_bar{position:sticky; top:.5rem; z-index:900; background:transparent}
.st-key-cm_nav_pill{
  max-width:1340px; margin:0 auto; border-radius:100px;
  background:rgba(9,12,18,.58);
  backdrop-filter:blur(24px) saturate(170%);
  box-shadow:0 16px 48px rgba(0,0,0,.58), 0 0 0 1px rgba(255,255,255,.10);
}
```

- **导航药丸化**：hover 才出底（`rgba(255,255,255,.09)`）；当前页用 tide 蓝玻璃药丸 + 亮字 + 发丝环。
- **事件源唯一**：只用原生 `st.page_link`，不自绘 `<a>`、不挂 JS 桥接——
  历史踩过的坑是「自绘链接 + 隐藏 page_link」双事件导致一次点击打开两个页面。
- **状态纯文字**：`● LIVE`、`SESSION SYNC` 不装盒（scrolltide 的处理方式）。
- **响应式**：1080px 收品牌副标、820px 收起状态文字；导航项 `white-space:nowrap` + 容器 `min-width:0`，**不再出现窄屏截字**（旧版白卡在 900px 以下会把「发票感知」裁成「发票感」）。

## 4. 首页：ScrollTide 叙事 + Coolors 色板（`app/components/dashboard_home.py`）

- **Hero**：左叙事右实时卡。底图是 AI 生成的碳网络纹理（`hero_carbon_mesh.jpg`），
  `mix-blend-mode:screen` 叠在玻璃卡上；标题用「马克笔」珊瑚色下划线；四枚状态芯片；
  coolors 标志性的**五色色板条**（DATA / LIVE / ESTIMATE / ALERT / LEDGER）。
- **联动**：Hero 两个 CTA、四张 KPI 卡、四个流程步骤**全部是真实 `st.page_link`**，
  点击直接进入对应页面（首页此前完全不能跳转，是本次补上的）。
- **令牌**：不再另立 `--dh-*` 色板，只做 `:root` 别名映射到 `--ct-*`，消除双令牌系统。

> **Streamlit 的一个坑**：每次 `st.markdown` 都是**独立元素**，HTML 里的开标签会被浏览器立即闭合。
> 把 CSS 变量写在 `.dh-wrap{--dh-blue:...}` 里等于写给一个空 div——后面所有内容都拿不到变量。
> 所以变量必须写在 `:root`（或 `body`）上。

## 6. ⚠️ 铁律：`.stApp` 绝对不能加定位类属性

**这是本次改造最贵的一个坑，值得单独写一节。**

现象：页面 DOM 有内容、布局 rect 正常、计算样式全部正常，但**屏幕上什么都没有**——
只有背景层在（因为 `background-attachment:fixed` 与 `position:fixed` 的伪元素不受影响）。

原因链：

1. Streamlit 的 `.stAppViewContainer` 是 `position:absolute; inset:0`；
2. 默认它的包含块是视口，所以高度等于视口高度；
3. 一旦给 `.stApp` 加 `position:relative`（或 `transform` / `filter` / `contain` / `will-change`），
   `.stApp` 就成了它的包含块；
4. 而 `.stApp` 自身高度是 **0**（它唯一的子容器是绝对定位，撑不起高度）；
5. `.stApp` 自带 `overflow:hidden` → **整页内容被裁成 0 高**。

排查手段（可复用）：

```js
// CDP 里问浏览器
getComputedStyle(app).height          // 0px
getComputedStyle(appView).height       // 0px
getComputedStyle(app).overflow         // hidden
document.elementFromPoint(x, y)        // 返回 <html>：内容不在命中测试树里
```

**结论**：`.stApp` 上只允许画背景与颜色，不许加 `position / transform / filter / contain / will-change / isolation`。
需要「固定背景」时用 `background-attachment:fixed`（背景层不参与布局），而不是给容器加定位。

## 7. 页面切换过渡

```css
.block-container > *{ animation:cm-page-in .5s var(--ct-ease-spring) both; }
.block-container > *:nth-child(n){ animation-delay: .02s * n; }
@keyframes cm-page-in{ from{opacity:.45; transform:translateY(14px)} to{opacity:1; transform:none} }
```

- 起始透明度用 **.45 而不是 0**：浏览器会**暂停后台标签页的 CSS 动画**，
  若起始态是 `opacity:0` 且用 `backwards` 填充，动画被暂停时内容会永久停在透明态（整页空白）。
  .45 既有淡入观感，又保证任何情况下内容可读。
- 错峰 0.02s/项，上限 8 项；`prefers-reduced-motion` 下全局降到 0.001ms。

## 8. 验收方式

视觉验收不靠肉眼猜，用 CDP 直接问浏览器：

```bash
node tools/verify_pages.js http://localhost:8501 _shots   # 逐页截图 + 异常探测
```

每页输出：截图字节数、`block-container` 高度、可见元素数、`stException` 文本。
**截图字节数是最快的判据**：整页空白时只有 ~140 KB（有内容时 1.3–1.9 MB）。
