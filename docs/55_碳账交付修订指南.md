## 0.5 ⚠️ 动手前必读：改工作簿的方式会决定数据还在不在

**这是最容易踩、后果最严重的坑，请务必看完再动手。**

工作簿里的排放量、配额可用量、结余、缺口**都是公式算出来的**，Excel 在保存时会把
**算好的结果（缓存值）一起写进文件**。而用脚本（`openpyxl` 等）打开再保存时，
**公式还在、缓存值没了** —— 读取端就再也读不到这些数。

实测（本仓库已在副本上验证）：

| 操作 | 结果 |
|---|---|
| 用 Excel 桌面打开 → 改 → 另存 | ✅ 公式与缓存值都在，数字正常 |
| 用 `openpyxl` 打开改一个文字格 → 保存 | ❌ **该工作簿里所有公式的缓存值全部变空** |

具体影响：

- 改 `quota_ledger.xlsx` 的 `Notes`（修订 1）→ **可用配额 / 结余 / 缺口 三个数直接变空**；
- 改 `carbon_ledger_main.xlsx` → `Trip_Detail` 的排放量与各级汇总**全部变空**。

**因此：**

1. **优先用 Excel 桌面打开改并另存**（最省事，也最安全）。
2. 若必须用脚本改：**改完再用 Excel 桌面打开该文件另存一次**，让 Excel 重算并写回缓存值。
   （`activity_data_field_dictionary.xlsx` 与 `evidence_index.xlsx` **不含公式**，脚本改完直接存即可。）
3. 交付前跑一次 §4.1 的自查脚本 —— 里面的「**前置 0 · 工作簿公式缓存值完好**」就是专门守这个坑的。
4. **数值一个都不许手填**。缓存值丢了就让它由 Excel 重算，**不要用常数替换公式**。
