## 1. 老师的要求（口径基准）

1. **把一段运输"聚成多段、分别计算"**——全程一个平均速度代入非线性排放公式有系统性偏差（Jensen 不等式），上个项目（全程均值 + 插值）最终偏差 13%、卡在省二。
2. **分段标准锚定工科论文的实测档位**——原话："按照工科论文的标准，**他已经测好了，那我们就在这儿聚合**"。
3. **段数克制**——"数据搞太多算力需求也大，分成几段这么去算"。
4. **定位是增量工作**——不是算法创新，是"贴近实际"的场景完善。

## 2. 有限数据下的实现方案

**没有 OBD 逐秒数据**，无法复现论文的逐秒 VSP 分布（吴睿中用 29 车 513.6 h 逐秒数据）。因此聚类的对象从"一条路线的秒"退到"一趟趟行程的速度"：

```
趟次表（12,167 趟，速度/距离/车型）
  → ① 数据门禁（借论文规则）
  → ② 论文锚定分箱（主口径，确定性）
  → ③ 1D K-means 归档（验证层，K 扫描 + 肘部法）
  → ④ 每档 VSP 代理值（复用 factor_model，不自造曲线）
```

### ① 数据门禁（吴睿中 2024 §1.3）
- 速度 `< 0` → `speed_negative`，剔除
- 速度 `> 110 km/h` → `speed_over_110`，剔除（论文：高速重货限速 100，>110 判异常）
- 缺失 → `speed_missing`，剔除
- 实测结果：**12,036 / 12,167 通过**，131 趟被标记

### ② 论文锚定档位（主口径）
| 档 | 范围 (km/h) | 依据 |
|---|---|---|
| 低速档 | [0, 20) | 吴睿中：<20 km/h 载重对 CO₂ 因子影响**显著**（满载 49t = 空载 18t 的 **2.8 倍**） |
| 中低速档 | [20, 40) | 白孝轩：重车 PEMS 测试均值 20~70 km/h 覆盖段 |
| 中速档 | [40, 60) | 两篇论文典型工况核心段；旧项目京东均值 ≈50 落此档 |
| 中高速档 | [60, 80) | 吴睿中：95.2% 逐秒数据集中在 **10~80 km/h** |
| 高速档 | [80, ∞) | 兜底档（论文 80 以上样本稀疏） |

边界**左闭右开**（20 归中低速、40 归中速），与论文 2 km/h 细档聚合成 20 km/h 粗档的口径一致。

### ③ K-means 归档（验证层）
- 1D Lloyd's + k-means++ 初始化，**纯 numpy 实现**（零新依赖），固定种子可复现
- K 扫描 2~6，**肘部法**（惯性二阶差分）选 K
- **最终档标签以论文为准**——K-means 回答的是"数据自然结构 vs 论文口径差多少"，是审计证据，不是另立标准

## 3.5 计碳规则（本模块只定规则，优化在下游 Q-learning）

**规则语句**：排放率由速度档决定——档均速 → 档 VSP → 档乘数；时间按本趟实际；因子基准沿用趟次法定因子 (g/km)。

```
kg_binned(趟) = 法定因子(g/km) / 72 × mult(档VSP) × 秒(本趟) / 1000
路段成本(kg)  = ef_gkm(档, 载重) × 路段里程 / 1000     ← Q-learning 的唯一接口
```

**对拍结果（2026-11-03，12,036 有效趟 / 211.2 万 km）**：

| 轨 | 总量 |
|---|---|
| 现行逐趟速度 VSP 轨 | 2,387.925 t |
| **分档规则轨** | **2,378.001 t** |
| 差异 | **−0.416%** |

分档碳汇总：低速档 EF 3,239.9 g/km（2,793 趟）→ 中低速 1,246.9 → 中速 998.1 → 中高速 1,024.8 → 高速 460.6 g/km。
低速档 EF 显著最高，与吴睿中"<20 km/h 载重效应显著"结论方向一致。

**分界声明**：本模块输出的规则卡（`vsp_seg_rule_table.parquet`）是运筹侧的**成本系数表**——Q-learning 同学以 `ef_gkm(档, 载重) × 里程` 作为路径/方案碳成本，本模块不包含任何优化、决策或搜索逻辑（有测试守这条线：规则卡禁止出现优化类字段）。

## 3.6 因子口径差异登记（方案 B：只登记，不改计碳逻辑）

### 问题

分档轨与主账用的是**两套因子**：

| 轨 | 因子来源 | 取值 | 版本 |
|---|---|---|---|
| 分档轨（本模块） | 趟次表**车辆组代表因子** `ef_g_km` | 6 个代表组锚点（394.56 / 544.75 / 759.24 / 1055.95 / 1374.67 / 1581.84） | — |
| 主账段表 | **(车型, 载重)** 因子 `factor_gkm` | 17 个组合（394.56 ~ 1581.84） | `JCB2023-BASE-v1` |

同一趟车，如果它落在哪个代表组与真实 (车型,载重) 不匹配，两条轨的碳值就不同。
**这不是 bug，是两个口径的差**——本节把它**逐趟落成可查表并登记在案**，**不改计碳逻辑**（分档轨仍用代表因子，因为规则卡是给下游运筹的独立系数表）。

### 对账口径

- 对拍对象：**主账物理轨** `kg_co2_phys`（分摊合计），与分档轨同为"ER × 时间"的物理口径，**不混法定口径**；
- 趟群：**通过速度门禁的同一 12,036 趟**（对齐后逐趟一一匹配，12,036/12,036 全匹配）；
- 里程逐趟一致（max diff 0.0），速度差 ≤ 5e-4 km/h → **差异不来自速度与里程，只来自因子**。

### 结论（2026-11-03 实测）

| 分档规则轨合计 | 2,378,000.852 kg |

## 3.7 输出纪律：缺失一律留空（不写 0、不写默认因子）

算碳输出端的三条硬纪律，已由测试锁住（45 项测试中的 4 项专门守这里）：

1. **被门禁排除的趟，偏差留空**——131 趟（>110 km/h / <0 / 缺失）的 `kg_co2_vsp_own`、`kg_co2_binned`、`binned_delta_pct` 全部是**空值**，不写 0.0。通过门禁的趟里"两条轨恰好相等"的 **107 个真 0 仍然是 0**——真 0 与假 0 必须分得清。
2. **缺因子不静默兜底**——因子 / 里程 / 速度缺失时，碳值留空（NaN），**不用默认因子 544.752 顶替**。静默兜底会把"没数据"变成"看起来有结果"。实测当前趟次表零缺失，所以该改动对碳值零影响（已逐值比对确认）。
3. **audit JSON 严格合法**——NaN → `null`（`json.dumps` 默认写出裸 `NaN`，严格 JSON 不合法，前端解析会炸）；空档的比率类指标（`avg_delta_pct` / `ef_binned_gkm`）留空，趟数 / 里程 / 碳量保留 0（那是真的 0 趟）。

另：K-means 的 `labels` 现在**对应输入顺序**（此前返回的是排序后的下标，调用方一旦按下标回指原始数据就会错位；当前调用点都丢弃 labels，故历史结果不受影响）。

> 上述改动**未改变任何碳值**：`vsp_seg_trips` / `vsp_seg_rule_table` 逐值完全一致，`vsp_seg_carbon` 仅 `binned_delta_pct` 列的 131 个被剔除趟由 `0.0` 改为空值，通过门禁的 12,036 趟**一行未动**，合计 2,378,000.852 kg / −0.416% 不变。

## 3.8 论文原文明细与速度-载重交互（白孝轩等 2026）

> 本节依据**原文全文 + 图 4/图 5/图 7 的拟合式**（正文只给结论，拟合式在图里）。
> 原文：白孝轩, 苗璐洋, 李朋, 等. 考虑载货质量的柴油车多元动态 CO₂ 排放因子定量研究[J]. 环境科学学报, 2026, 46(2): 111-122. DOI: 10.13671/j.hjkxxb.2025.0382
> 复核脚本：`tools/verify_bai2026_figure_model.py`（逐档逐车型因子对拍）、`tools/verify_lowspeed_carbon.py`（低速段尾部排查）、`tools/verify_docs58_numbers.py`（本节数字 → 台账口径重算并断言，51 项）

### 3.8.1 原文给出的完整模型与系数

图 4a / 图 5 的核心式（g/km，基于行驶里程）：

```
EF(车型, 速度v, 载重M) = k(车型,v)·M + b(车型,v)
```

| 车型 | k 载重边际斜率 (g/km/t)<br>30 / 60 / 90 km/h | b 空载基准 (g/km, 国III)<br>30 / 60 / 90 km/h |
|---|---|---|
| 轻型 | 58.57 / 25.07 / 3.10 | 423.85 / 273.64 / 315.58 |
| 中型 | 34.73 / 14.94 / 1.85 | 370.17 / 237.50 / 272.04 |
| 重型 | 34.39 / 14.72 / 1.82 | 846.69 / 530.21 / 578.24 |

单位货物质量因子（图 4c）：`EF_G = k + b/M`，即"距离基准因子 ÷ 货物质量"。

图 7 环境修正系数（R²=1.00，以北京近 10 年均温 17.3℃、均海拔 47 m 为基准）：

```
k_T(T) = 2.08e-4·T² − 0.01·T + 1.11        # 温度，最低点约 24.3℃
k_A(A) = 5.498e-8·A² − 1.81e-4·A + 1.008    # 海拔，最低点约 1647 m
```

> 图 4（合并拟合）与图 5（分排放标准拟合）系数略有差异，如轻型 30 km/h：图 4 为 `58.46x + 416.23`，图 5 为 `58.57x + 423.85`。本节统一采用**图 5 国III 基线**口径。

### 3.8.2 三条结构发现

1. **排放标准只改截距 b，不改斜率 k**——除轻型 90 km/h 国III（斜率 5.10，其余标准 3.10）外全部如此。含义：**标准升级省的是"空载基准排放"，不是"载重边际排放"**。重型 30 km/h 国III→国VI：截距 846.69→534.32（省 312 g/km）；中型 30 km/h 国III→国V：截距 370.17→**566.55**（涨 196 g/km）。原文口径的降幅：重型国VI 比国III 低 22.92%~31.77%，轻型低 0.84%~1.24%，**中型国V 比国III 反而高 30.98%~46.49%**。
   → **对方案建议的硬约束**："换新车降碳"只对空载/轻载车成立，满载车收益很小；中型车换新标准可能**反向**。
2. **载重斜率随速度急剧衰减**——重型 34.39(30) / 14.72(60) / 1.82(90)，30 与 90 km/h 相差 **18.9 倍**。吴睿中原文独立佐证同一规律："随着速度的提高，载重对 CO₂ 排放因子的影响逐渐减小"，并给出"考虑实际载重可使测算误差减小 3%~12%"。
3. **实测覆盖只到 30 km/h**——原文的典型速度只有 30 / 60 / 90 km/h，**<30 km/h 无实测**。

### 3.8.3 我们因子表的"等效工况"

我们因子表（吴睿中 LC-VSP 表，v=50 基准）载重锚点 4.5 / 12 / 18 / 30 / 40 / 45 t ↔ 394.56 / 544.752 / 759.24 / 1055.952 / 1374.672 / 1581.84 g/km，隐含斜率 **29.32 g/km/t**（端到端；中段 18→40t 为 27.97）。

反查论文：29.32 等效于**中/重型约 38 km/h、轻型约 56 km/h** 的工况。

> 结论：**我们的因子表是一张"中速平均工况表"**，而实际运行速度中位 36.24 km/h、里程 53.5% 落在 60~80 km/h。**因子表的等效工况与数据实际工况存在错配**——这正是"分档"的价值所在：不是"分得更细更准"，而是**让不同速度段各用自己的因子**。

交叉验证（两篇论文互证）：我们 18t→45t 为 **+108%**，正落在吴睿中"平均工况下满载相较空载增加 24%~113%"区间内；用其低速段"满载 49t = 空载 18t 的 2.8 倍"反推斜率 44.1 g/km/t，与白孝轩 30 km/h 的 34.39~58.57 同量级。**我们的因子表本身没错，错配在"没有速度条件化"。**

### 3.8.4 物理轨 vs 实测对拍（同口径 g CO₂/km）

我们物理轨单位里程碳 `EF_phys = factor_gkm × mult(vsp(v_clean)) × 50/v_clean`（`v_clean` 为**清洗后速度**：v≤1 km/h 按行业均速 50 km/h 兜底，见 §3.8.5），与论文实测 EF 同为"每公里排放"，可直接比。

单点验算（重型 30t）：

| 速度 | 我们 EF_phys | 论文 EF | 相对差 |
|---|---|---|---|
| 25 km/h | 1890.2 | 1878.4 | **−0.6%** |
| 35 km/h | 1418.0 | 1727.3 | +21.8% |
| 50 km/h | 1056.0 | 1274.0 | +20.6% |
| 65 km/h | 889.5 | 915.3 | **+2.9%** |
| 80 km/h | 781.0 | 745.8 | **−4.5%** |
| 95 km/h | 689.1 | 632.8 | −8.2% |

分档合计：低速档 −64.37%、中低速档 −0.07%、中速档 −0.22%、中高速档 −13.91%、高速档 −18.24%；总计我们 2,302.2 t vs 论文口径 1,923.0 t（−16.47%）。

> **在论文有实测覆盖的 30~90 km/h（占我们里程 86.6%），物理轨与第三方实测大体同量级**（该区间内多数档位 |Δ| 在 5% 以内，35~50 km/h 段高估约 20%）——这是可以写进答辩的**第三方实测背书**。

### 3.8.5 低速段：覆盖缺口（诚实边界，勿外推）

| 速度段 | 里程占比 | 碳占比 | 论文实测覆盖 |
|---|---|---|---|
| <30 km/h | 9.8% | **20.1%** | 无（典型速度最低 30 km/h） |
| 30~90 km/h | 86.6% | 78.4% | 有 |
| >90 km/h | 3.6% | 1.5% | 无 |

我们的 `EF_phys ∝ 50/v` 在低速**急剧上升**（但不发散到无穷——v≤1 km/h 由行业均速 50 km/h 兜底，见 §3.8.4）。按台账真实口径（`kg_co2_phys_gross / trip_km × 1000`）测得极值 **46,894.8 g/km**（trip 6938，1.383 km/h、8.00 km，碳 375.16 kg）；v≤1 km/h 的 **49 趟**因 50 km/h 兜底落在 **394.6~1,056.0 g/km**（合计 446.1 kg）。碳量高度集中：Top 20 趟占 5.80%、Top 100 趟占 16.76%、Top 1000 趟占 69.12%。

**这个差异不能读成"论文说我们算错了"**——论文在 <30 km/h 没有实测，上表低速档 −64.37% 是拿 30 km/h 实测值 clamp 外推出来的。真实问题是一个**建模选择**：

> 低速段（占里程 9.8%）贡献了 **20.1%** 的物理碳，因为我们的模型把"门到门均速低"的时间**全部按发动机持续运转折成了碳**。而项目早就定过规矩——**「枢纽停留 ≠ 怠速，只量化不折碳」——这条规矩目前没有落到代码里**：趟级均速分不开"行驶"与"停留"，模型只能一刀切。
> **而这恰恰是 OBD 秒级剖面（G1）要解决的问题**：论文能覆盖 30~90 km/h 的 86.6% 里程，剩下的 9.8% 只能靠我们自己的实测。

### 3.8.6 温度修正系数落到本项目

按上海/深圳月均温套 `k_T`（近似值，实际应按出发城市 × 月份取气温，海拔 `k_A` 另计）：

| 月份 | 月均温℃ | k_T | Δ | 该月碳量 |
|---|---|---|---|---|
| 2023-11 | 12.0 | 1.0200 | +2.00% | 409.2 t |
| 2023-12 | 8.0 | 1.0433 | +4.33% | 637.9 t |

净 **+35.8 t（+3.42%）**——冬季月份因子系统性偏高，我们目前**完全没有环境维度**。

### 3.8.7 这节带来的三个待办（均为"算碳"，需另开版本号走并列轨）

1. **低速段碳口径**（影响 20% 的碳量）：显式区分行驶/停留，或对 < 某阈值 km/h 设怠速上限不折碳——与末端配送口径、枢纽停留是同一件事，**待拍板**。
2. **速度-载重交互**：按分车型 `k(车型,v)` 给 5 个速度档各定载重斜率（当前模型把载重与速度完全解耦：实测 EF 的载重倍数在 5 个速度档上恒为 3.49~3.90，极差 12.0%，而论文实测 k 相差 18.9 倍）。
3. **温度/海拔修正 `k_T` / `k_A`**：+3.42%，按出发城市 × 月份维度接入。

## 3.9 多维 K-means 并列轨（2026-11-06 用户确认）

### 定位

原有 §3.3 的 1D K-means 只对**速度**做归档，回答“数据自然分层与论文档位差多少”。本节的多维 K-means 是**独立的描述性归档轨**：按用户确认的六项口径，对“趟/路段”整体画像，输出可回连的 `cluster_id`，供后续按路段、车牌做分层统计。它**不改变** E₀ 主账、28 条主闸门、分档规则卡或任何碳值。

### 口径

| 项 | 历史趟次（proxy_v1） | OBD 文本段（obd_v1） |
|---|---|---|
| 粒度 | 一趟一行（`trip_id`） | 一段一行（`segment_id`） |
| 特征 | 平均速度 / log1p(里程) / 载重 | 平均速度 / 平均转速 / 实际扭矩 / 瞬时油耗 / 怠速占比 / log1p(里程) |
| 载重 | 趟次表无载重，从主账 `baseline_carbon` 按 `trip_id` 取 first 代理 | 文本段无载重，**不硬造**；接入车辆主数据后再评估 `obd_load_v1` |
| K | 固定 3（用户拍板；K=2–6 只进审计） | 同左 |
| 初始化 | 纯 numpy k-means++，`n_init=10`，`seed=20261106` | 同左 |
| 缩放 | 逐列 robust：中位数中心 + IQR 尺度 | 同左 |
| 缺失 | **不插补**：任一特征缺失，该行 `cluster_id` 留空 | 同左 |
| 物理门禁 | 速度 <0 或 >110 km/h 剔除（与 §2① 同口径） | 同左 |

### 实测（2026-11-06，12,167 趟）

- 输入 12,167，有效 **12,036**，剔除 **131**（全部 `speed_out_of_range`，与分档轨完全同一批）；缺失 0。
- K=3，簇规模 **6,644 / 4,001 / 1,391**，inertia **6,991.91**，迭代 16 次；抽样轮廓系数 **0.425**，seed 与 seed+777 两次独立复跑 ARI **1.0**（同一数据上的初始化稳定性，不是跨数据稳定性）。
- K 扫描（inertia / silhouette）：K=2 10,692.5 / **0.533**；K=3 6,991.9 / 0.422；K=4 5,755.3 / 0.335；K=5 4,837.4 / 0.360；K=6 4,039.9 / 0.368。K=2 的轮廓系数最高，但只分“快/慢”；**K=3 是用户拍板的业务首版固定值**，不因轮廓系数改 K。
- 簇心（速度 km/h、里程 km、载重 t）：

| cluster_id | 趟数 | 占比 | 平均速度 | 平均里程 | 平均载重 | 代表车型 |
|---|---:|---:|---:|---:|---:|---|
| 0 | 6,644 | 55.20% | 23.57 | 25.88 | 6.34 | 4.2 米厢式 |
| 1 | 4,001 | 33.24% | 54.76 | 100.15 | 13.19 | 9.6 米厢式 |
| 2 | 1,391 | 11.56% | 60.27 | 785.67 | 37.02 | 牵引车头 |

读法：0 簇是“短途轻载低速”，1 簇是“中长途中载”，2 簇是“长途重载”；簇 2 速度与簇 1 接近但里程/载重把长途重载单独分出。**这是描述性画像，不是新的碳口径**。

### 输出与回连

- `vsp_seg_clusters.parquet`：每趟一行，含 `grain / unit_id / feature_set / cluster_id / cluster_distance / n_missing_features / plate_id` 与三特征值；`cluster_id` 为可空 `Int64`。

- `vsp_seg_plate_map.parquet`：原车牌 → 16 位加盐 SHA-256；**原车牌只在该表**，归属表只落 `plate_id`。
- `vsp_seg_cluster_audit.json`：门禁计数、缺失/剔除原因、缩放参数、K 扫描、局限。
- `vsp_seg_trips.parquet` 追加 `cluster_id`；131 趟被门禁剔除的行留空，不写 0。

## 4. 诚实边界（答辩主动说）

1. **输入是趟级平均速度，不是逐秒剖面**——分段降低的是"档位错配"误差，还不能消除"段内瞬态"误差（那是 G1，等 OBD+GPS）。
2. **载重维度未接入**——论文证明 <20 km/h 档载重效应 2.8 倍，但趟次表暂无真实载货质量；因子表 (车型,载重) 锚点已具备，真实载重接入后同框架升级为 (速度档 × 载重档) 二维聚合。
3. **档位来自论文、系数来自论文，我们做的是"归档 + 审计"**——这正是老师要的增量：方法不发明，贴合实际。
4. **因子口径与主账不同（已逐趟登记，未改逻辑）**——分档轨用车辆组代表因子、主账用 (车型,载重) 因子，绝对口径差 **+3.2907%**（净），拆为因子效应 +3.7218%（集中在 428 趟、承载 20.8% 碳，逐趟可查 `vsp_seg_factor_recon.parquet`）与分档乘数效应 −0.4156%。这是并列轨的口径差异，**不影响 E₀ 主账（2,258.44 t）与 28 条主闸门**。
5. **100~110 km/h 的 55 趟仍进计碳**——上游把 185 趟标成"速度>100 km/h，待核验"，其中 55 趟未触发本模块的 >110 剔除线，仍参与计碳（22,483.4 kg，占 0.945%）。口径透明：剔除与否对结论不敏感（碳量 ±0.945%，两轨差 −0.416% → −0.420%），详见 §5。
6. **因子表没有速度条件化**——我们的因子表隐含载重斜率 29.32 g/km/t，等效于论文的 **38 km/h（中/重型）/ 56 km/h（轻型）**工况（反查依据见 §3.8.1 系数表）；而实测里程 53.5% 在 60~80 km/h。因子表的等效工况与数据实际工况**错配**，这正是分档要解决的问题（详见 §3.8.3）。
7. **低速段（<30 km/h）是实测覆盖缺口，不是模型算错**——该段占里程 9.8% 却贡献 **20.1%** 的物理碳，因为 `EF_phys ∝ 50/v`（v≤1 km/h 按行业均速 50 km/h 兜底，不发散到无穷）把低速时间全按发动机持续运转折成了碳；白孝轩原文实测只覆盖 30/60/90 km/h，**无法为 <30 km/h 背书**。这一段只能靠我们自己的 OBD 秒级剖面（详见 §3.8.5）。
