## 5. 坑表（今天真踩过的）

| 现象 | 原因 | 处理 |
|------|------|------|
| `[HTTP] -1` / `begin failed` | 板子与 PC 不同网段，或 `SERVER_URL` 还是 192.168.43.9 的旧 IP | 手机热点改名后必须同步改固件；看 `ipconfig` 的 IPv4 |
| HTTP **401** `设备未授权` | 设备未登记 / 令牌 sha256 不匹配 | S2 登记；令牌区分大小写 |
| HTTP **429** | 单设备超 60 请求/分钟 | 合批或降频（30 条/10 s ≈ 6/min，安全） |
| 400 `单批最多 5000 条` | `BATCH_N` 过大 | 拆批，`OBD_MAX_BATCH=5000` |
| `accepted=0, rejected>0` | 缺 `vehicle_id` / 裸 `ts` 无时区 / 两种油耗都没有 | 查 `obd_rejects.csv` 的 `reason` |
| `UnicodeEncodeError ... \u2082` | GBK 控制台 | `$env:PYTHONIOENCODING='utf-8'` 或 `chcp 65001` |
| 页面数字没变 | ① 没跑 pipeline；② **内层读取函数永久缓存**（`app/services.py` 的 `_read_parquet` / `_read_json` 原本无 TTL），外层 30 s TTL 过期后仍拿到旧对象；③ 改了 `app/*.py` 但只是按 `R` 重跑 —— **导入过的模块不会重载** | ① 先 S5；② 已改为把结果文件 mtime 作为缓存键（`mtime_token()`），文件一变缓存即失效；③ 改代码必须**重启 Streamlit**（`tools.launch` 进程），按 `R` 不够 |
| :5000 起不来 | 端口被别的进程占着（旧网关 / 上次没退干净） | 按端口查 PID 再杀：`Get-NetTCPConnection -LocalPort 5000 -State Listen` → `Stop-Process -Id <PID>` |
| `python -m src.pipeline` 退出 1 + `[SAFE]` | data/raw 顶层无 xlsx/xls/csv 且结果来源为 real | **正常保护**：把附件1/附件2 放回 data/raw 后重跑；不要用 `--allow-demo-overwrite` 覆盖真实结果 |

## 6. 口径红线（改代码前先读）

1. **E0 只由主链产生**：实测轨、Q-learning、页面实时动作都不得改写 `kpi.json` / `baseline_carbon` / `wide_data`。
2. **缺油耗就没有碳**：两种油耗字段都没有的记录进 reject，**绝不填 0**。
3. **demo 必须标** `is_demo`，校准时被排除（`src.obd_calibration` 只吃真实点）。
