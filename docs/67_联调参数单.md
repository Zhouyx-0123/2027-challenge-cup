常用命令（仓库根目录执行）：

```powershell

python -m tools.device_tokens add --device-id TRK-LOOP-001 --note "OBD 联调车机"    # 登记，明文只打印一次
python -m tools.device_tokens rotate --device-id TRK-LOOP-001                        # 轮换，旧令牌立即失效
python -m tools.device_tokens remove --device-id TRK-LOOP-001                        # 吊销
```

拿到明文后可先在本机对拍（不联网）：

```powershell
python -c "from src import device_auth as d; print(d.verify('TRK-LOOP-001','<明文>')); print('auth_enabled=', d.auth_enabled())"
# 期望：(True, 'ok') 与 auth_enabled= True
```

## 7. 401 / 429 的处置

### 401 —— 设备未授权

对外话术统一为 `设备未授权：令牌缺失或不匹配（请用 tools/device_tokens 登记设备）`（**故意不区分**设备不存在还是令牌错，防枚举）；OBD 通道还会多返一段 `unauthorized: [{device_id, reason}]`，原因码只用于自查：

| `reason` | 含义 | 处置 |
|-----------|------|------|
| `no_token` | 请求头没带 | 固件 `DEVICE_TOKEN` 还是空串 → 填明文重烧 |
| `unknown_device` | 该 `vehicle_id` 没登记 | `add --device-id <该值>`，或把 `VEHICLE_ID` 改成已登记的车号 |
| `bad_token` | 摘要对不上 | `rotate` 拿新明文重烧；注意区分大小写、别带引号 / 空格 |
| `disabled` | 设备被停用 | 重新 `add`（启用）或 `rotate` |
| `no_registry` | 注册表为空 / 路径不对 | `list` 看打印的注册表路径；检查 `SENSOR_DEVICES_FILE` |

排查顺序：`python -m tools.device_tokens list` → `/api/health` 看 `auth.enabled` 与 `auth.devices` → 固件请求头名必须是 `X-Device-Token`。

### 429 —— 请求过于频繁

- 响应体 `{"status":"error","message":"请求过于频繁，请稍后再试"}` + `Retry-After`（OBD 通道固定 60 秒）。
- 阈值：每设备 **60 次/分钟**（`SENSOR_RATE_LIMIT_PER_MIN`，默认值即 60）。
- 处置：**合批**（`BATCH_N` 上限 5000，超了是 413 `单批最多 5000 条`）或**降频**。当前 30 条/批、10 s 一条 ≈ 6 次/分钟；`SEND_ONCE=false` 时 `loop()` 每 30 秒一批 = 2 次/分钟，都安全。
- 演示临时放宽才动环境变量，别写进交付配置：`$env:SENSOR_RATE_LIMIT_PER_MIN="120"`（重启网关生效）。
