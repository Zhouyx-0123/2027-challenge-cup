## 0　一句话

把"拥堵"从**一个速度点**升级成**一个分布**（期望、CVaR、拥堵程度），再把 Dijkstra 的边权做成时间与风险的函数，最后给最后一公里一套"GA 排单 + 剩余子问题重排"的算法。

## 1　背景与目标

原实现有三处缺口：

| 缺口 | 表现 | 本版做法 |
|---|---|---|
| 拥堵是点估计 | 无法回答"可能堵多少" | 速度对数正态 + CVaR |
| 选路是出发快照 | 跨高峰时 ETA 偏 | 时变边权（TD） |
| 最后一公里缺失 | 多站点/时间窗无法排 | GA+爬山 + 剩余重排 |

## 2　拥堵概率模型

### 2.1 速度分布与矩

```
ln v ~ N(μ, σ²)，μ = ln(v_mean) − σ²/2
E[T] = (L / v_mean) · exp(σ²)          ← 方差会抬高期望
Var[T] = E[T]² · (exp(σ²) − 1)
CVaR90 = μ_T + 1.755·σ_T               ← 正态近似
P(准时) = Φ((l − μ_T)/σ_T)
```

`exp(σ²)` 是"方差拖累"：CV=0.25 时 E[T] 比 `L/v` 高 6.4%，CV=0.30 时高 9.4%。

### 2.2 参数标定（2023 路网级模拟数据集）

| 道路 | 段数 | 均速 | 平均拥堵度 | 拥堵占比 | 速度 CV |
|---|---|---|---|---|---|
| 国道 | 60,721 | 55.5 | 0.107 | 15.9% | **0.235** |
| 城市 | 85,027 | 39.5 | 0.168 | 12.0% | **0.289** |
| 高速 | 74,909 | 87.1 | 0.148 | 12.5% | **0.248** |

配置里的 `cv_by_road_class` 就是这组值（道路等级 1/2/3/4 映射为高速/城市/国道/匝道）。

### 2.3 CVaR 验证（320 条真实路线，每条 ≥8 趟）

| 模型 | 中位偏差 | MAE | P90 覆盖率（目标 90%） |
|---|---|---|---|
| 正态近似 | **−2.2%** | **6.5%** | **89.1%** |
| 对数正态 | −0.4% | 13.5% | 89.6% |

按波动性分组：

| 路线 CV | 条数 | 中位偏差 | MAE |
|---|---|---|---|
| < 0.3 | 141 | −0.5% | 3.1% |
| 0.3–0.5 | 56 | −3.7% | 8.4% |
| > 0.5 | 123 | −6.0% | 9.6% |

**结论**：正态近似通过覆盖率检验；高波动路线（CV>0.5）尾部偏乐观约 6%。

**重要**：路线级 CV 中位数 0.365，远高于分段 CV（0.25）。用分段 CV 估路线 CVaR 会**低估 12.9%**，所以默认 CV 应按路线/时段标定，而不是逐段。

### 2.4 拥堵程度与屏蔽阈值

```
degree = 1 − v / v_free        （0=畅通，1=堵死）
```

3,183 条路线的拥堵度：p50 0.25、p90 0.60、p99 0.81；**>0.8 的只占 1.4%**，所以 `mask_degree_max=0.8` 是"精准打击"的阈值。

### 2.5 长途：相关性与事故项

| 口径 | E[T] | σ | CVaR90 |
|---|---|---|---|
| 独立、无事故 | 8.66 | 0.91 | 10.26 |
| ρ=0.35 | 8.66 | 1.35 | 11.04 |
| ρ=0.35 + 事故 4 次/千 km | 9.20 | **4.90** | **17.80** |

长途尾部由**事故**主导（σ ×3.6），不是日常拥堵；所以长途用 CVaR 主要是给"保守到达区间"，而不是选路。

## 3　动态选路

### 3.1 静态 vs 动态

| | 静态（现状） | 动态（本版） |
|---|---|---|
| 边权时刻 | 出发快照，全程沿用 | 到达各节点时取速度 |
| 风险 | 无 | `λ·(CVaR_e − E_e)` |
| 拥堵 | 只影响时间 | `w·degree` 显式定价 |
| 重规划 | 成本改善 >8% | 每节点重算 + 事件（速度骤降 >30%） |

### 3.2 边权

```
cost(e, t) = T(e,t) + k_c·C(e,t) + k_m·M(e,t) + w·degree(e,t) + λ·(CVaR_e − E_e)
```

### 3.3 实测差（演示网，单条路径）

| 出发 | 静态 | 动态 | 差 |
|---|---|---|---|
| 07:50 | 8.09 min | 8.16 min | +0.9% |
| 17:00 | 5.97 min | 6.11 min | +2.3% |

短途差别是秒级；长途跨高峰会放大到 5–15%。

### 3.4 拥堵权重的翻转阈值

两走廊算例（穿城 13.3 min / degree 0.50；绕城 15.3 min / degree 0.08）：

```
w* = ΔU_其他 / Δdegree = 6.77
```

`w>6.77` 时选择从穿城翻到绕城。演示网里"最快=最畅"，w 加到 200 也不翻——**不是方法无效，是路网没有可替换的路**。

## 4　最后一公里

### 4.1 算法选择：GA 而不是表格 Q

12 客户、时间窗 ±20 min 的实例上对照：

| 算法 | 成本 | 迟到 | 耗时 |
|---|---|---|---|
| GA+爬山（专利 CN112580865A 思路） | 214.11 | 0 | 0.7 s |
| 表格 Q-learning（12k 回合） | 差 0–630% | 大片迟到 | 0.5 s |
| 表格 Q-learning（40k 回合） | 部分种子追平，1 个仍差 300% | 0–41 min | 1.5 s |

**结论**：最后一公里用 GA 排单；Q 只保留为决策层候选（接不接受急单/何时重排）。

### 4.2 扰动重排

```
扰动（新急单/路况变） 
  → 剩余点 + 当前位置建成子问题（时间窗平移 −elapsed）
  → GA 重解 → 映射回原编号
```

### 4.3 碳口径

| 载具 | 口径 | 默认值 |
|---|---|---|
| 电动车 | kWh/km × 电网因子 | 0.25 × 0.5568 = 0.1392 kg/km |
| 柴油车 | L/km × 2.63 | 0.12 × 2.63 = 0.3156 kg/km |

## 7　边界与已知限制

1. **CVaR 是正态近似**：高波动路线（CV>0.5）低估约 6%，需修正系数；
2. **风险不可加**：边级 σ 相加会忽略相关性，候选生成可用，最终排序应模拟校验；
3. **事件检测是启发式**：速度骤降 >30% 才触发，阈值需按线路调；
4. **最后一公里没有 Q**：表格 Q 样本效率不够，暂用 GA；Q 的位置在决策层；
5. **数据依赖**：CV 的默认值来自 2023 模拟集，真实线路需按月重标定。
