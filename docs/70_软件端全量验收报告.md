### 5.1 从原始附件复算：受限

在 D:/oceanbase02/_accept_pipeline 运行 python -m src.pipeline，退出 1：

```text
[SAFE] data/raw 为空，现有结果表来源为 real。为防止演示样本覆盖真实结果，本次拒绝执行。
如确认要重建演示数据，请显式追加 --allow-demo-overwrite。
```

原因：data/processed/_source.json 记录 source=real（2023 订单/运单 xlsx，36,329 行，生成于 2026-10-24），但 data/raw 只有 obd_gps/obd_stream.csv；京东原始 xlsx 不在仓库，*.xlsx 与 data/raw/ 被 .gitignore 排除。不能加 --allow-demo-overwrite，否则会覆盖真实结果。
