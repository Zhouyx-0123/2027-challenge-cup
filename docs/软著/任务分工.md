## 四、手册 60 页拆法

每页不少于 30 行；建议 A4、正文 10.5–11 pt、页眉软件名/版本、页脚页码。

| 页码 | 内容 | 负责人 |
|---|---|---|
| 1–10 | 封面、目录、系统概述、技术架构 | 文档 A |
| 11–20 | 运行环境、安装启动、数据准备、口径说明 | 文档 A |
| 21–30 | 概览、基准核算、高排放诊断 | 文档 B |
| 31–40 | 替代方案、成本效益、碳会计台账 | 文档 B |
| 41–50 | 路线实验室、电动化测算、车队 TCO | 文档 C |
| 51–60 | 碳模型/公式、审计与披露、FAQ、附录 | 文档 C |

截图要求：

- 不出现 waybill_no、order_no、plate、invoice_no、客户名、手机号；
- 不出现 GitHub 地址、API key、终端路径；
- 统一 1600×1000 或更高，深色主题；
- 每张图配 2–4 行说明，避免整页只有图。

## 五、源代码 PDF 要求

- 前 30 页 + 后 30 页，各连续；
- 每页不少于 50 行；
- 页眉：`碳慧智算物流碳感知智能决策系统 V1.0    第 XXX 页`；
- 等宽字体，黑白，A4；
- 不放 GitHub/VSCode 界面、侧边栏、终端；
- 不放第三方库源码、密钥、真实数据；
- 已有文本：`docs/软著/源代码/源代码_前30页.txt`、`后30页.txt`。

## 六、提交前 Go / No-Go

必须全部为“是”：

- [ ] 申请主体已确认，证件齐全；
- [ ] 合作/委托/职务作品权属文件已签；
- [ ] 名称、版本在申请表/源页/手册三处一致；
- [ ] 源代码 30+30 页，每页 50 行；
- [ ] 手册 60 页，每页 30 行，截图脱敏；
- [ ] 发表状态=已发表，首次发表日期有依据；
- [ ] 源页/手册/截图不含真实业务数据和密钥；
- [ ] 公开仓库数据风险已处置或已书面确认可公开；
- [ ] 复核人签字。

任何一项“否”，不要提交，先补。
